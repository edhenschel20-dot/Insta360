# Keyframes with easing

The manual method — slower than the others, but the right choice for a
deliberate camera move (a reveal, a crane shot, a slow pan) rather than
"follow this subject."

## Steps
1. Scrub to where the move should start. Set the framing (direction, FOV),
   then tap to set a **keyframe**.
2. Scrub forward 2–3 seconds (or to wherever the move should land). Set the
   new framing — the reveal, the new direction — and set a second
   **keyframe**.
3. Tap the line between the two keyframes and choose a curve. **Ease
   In/Out** is the general-purpose choice — it starts and ends the move
   smoothly instead of snapping. Other curves exist (Linear, Ease In, Ease
   Out, Transition Delay, Quick In/Out, Hard Cut) for different effects
   (menu names vary by app version).
4. Preview and adjust either keyframe if the timing feels off.

## Tips
- **Two keyframes only** works because the physical camera move was already
  done at shoot time — if you walked, raised the stick, or turned smoothly
  while filming, the edit only has to connect a start point to an end
  point. See the settings and shot-recipe pages for shooting technique.
- Keep it to two keyframes unless there's a real reason for a third (e.g. a
  sharp change of direction mid-move). More keyframes means more time
  dragging things around.
- Keyframe copy/paste doesn't exist in the phone app — if you want to reuse
  a reframe across similar clips, that's a Studio (desktop) feature, where
  duplicating a clip carries its edit data with it.
- If you're building a standard move repeatedly (rise, orbit, reveal),
  check whether a **Movement template** already does it in one tap before
  hand-placing keyframes.
