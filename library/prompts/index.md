# Edit prompts

Ready-to-paste prompts that get **Claude** (the Claude desktop app, with
computer use) to edit a 360 clip in **Insta360 Studio**. It reframes the
clip, cuts the dead time and adds transitions, then exports a finished video.

**Each page holds the current best prompt for that situation.** When a
test finds a better one, the old prompt is replaced, so the page is
always the one to use. What we tried, and why it changed, is kept in the
[test log](test-log.md).

## Pick your situation
| Situation | Status | Prompt |
|---|---|---|
| Fireworks | Version 3, not tested yet | [Fireworks](fireworks.md) |
| Parade | Version 1, not tested yet | [Parade](parade.md) |
| Anything else | Build one from the shared rules | [Build your own](build-your-own.md) |

Still to come: luau, Kapalua golf, beach, snorkel, Road to Hana.

## How to use a prompt
1. Read **[How to run it](how-to-run.md)** the first time: getting the clip
   onto the laptop, which model to use, and checking the cost.
2. Open the situation page and tap the **copy** button on the prompt.
3. Paste it into a **new chat** in the Claude desktop app.
4. Afterwards, tell Claude Code how it turned out, so the prompt can be
   improved and this page updated.
