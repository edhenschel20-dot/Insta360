# Foldable Selfie Stick Remote Kit

Firmware 1.13.21 (2026-09-15) added support for a new Foldable Selfie Stick Remote Kit accessory, described as enabling "gimbal-like" video output. It's the same accessory line introduced for the X6, now also supported on the X5. Beyond the release note, details of how it changes your shooting or editing workflow aren't published yet.
