# Bodyboard / Boogie-Board Mount
The X5 rides on the nose of a boogie board — above the water on the wave, then flip the board and it films the reef underneath.

**Difficulty:** Medium · **Works on X5:** Yes (dive case for anything that goes under)

## Shoot it
1. Mount the X5 to the nose of the board — the official Floating Surfboard Mount (3M adhesive, floats if knocked off) or an Action Mount whose ¼" thread locks so the lens direction can't twist.
2. Fit the Invisible Dive Case if the board will go fully under (reef swims, flipping the board to look beneath); skip it if the board only gets splashed.
3. Leash the camera to the board as a backup to the mount.

## Edit it (phone app)
1. Turn Direction Lock off so the world tilts naturally with the wave instead of fighting to stay level.
2. The seam runs fore-aft along the board when it's mounted with the lenses facing the rails — keep that in mind when reframing so people don't end up split across it.

## Settings
Full reference: [Underwater diving](../settings/underwater-diving.md) if going under; [Snorkelling & water](../settings/snorkelling-and-water.md) if it only gets splashed.
- 5.7K60 in the dive case, standard mode if surface-only.

## Tips
- This is a good one for a calmer reef day rather than big surf — flipping the board to look under works best when the water isn't churned up.
- Pairs with [Over-Under Split Shot](over-under-split-shot.md) at the surface between flips.
