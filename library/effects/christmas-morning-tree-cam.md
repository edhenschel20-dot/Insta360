# Christmas-Morning Tree Cam
Set the camera up beside the tree the night before, so it's already rolling when the kids come down — nobody has to hold a phone, and the whole thing is one continuous clip instead of a series of grabbed photos.

**Difficulty:** Easy · **Works on X5:** Yes

## Shoot it
1. The night before: stand the stick and mini tripod beside the tree at sitting height, lenses toward the sofa and the pile of presents.
2. Use [Timed Capture](hands-off-triggers.md) to have it start itself the next morning, or just start it manually with a peace-sign photo trigger if someone's up early enough.
3. Indoor lights call for **PureVideo 5.7K30, EV −0.3, WB auto** — see [Events & indoors settings](../settings/events-and-indoors.md).
4. Then leave it. Let the whole hour run as one clip rather than stopping and restarting for each present.

## Edit it (phone app)
1. [Deep Track](../editing/deep-track.md) each child in turn, pausing and resuming the tracker when the "story" moves from one child to the next.
2. [Split Screen / MultiView](split-screen-multiview.md) to show the opener and the gift-giver's reaction together.
3. A [Time Freeze](../effects/time-freeze-animated-photo.md) on the big reveal moment, if there is one.

## Settings
- PureVideo 5.7K30, EV −0.3, WB auto (indoor lighting).
- Timed Capture set the night before if you want it to start itself.

## Tips
- This is the same pattern as [Hands-Off Triggers](hands-off-triggers.md)'s Timed Capture, applied to one specific morning.
- **[general advice]:** no 360-specific tutorial exists for this exact setup; it's built from this project's own timed-capture and indoor-settings pages, plus raw single-camera Christmas-morning uploads as look references.
