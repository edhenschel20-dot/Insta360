# Sky Transition
Clip A tilts up until the frame is nothing but sky; clip B starts the same way and tilts back down onto a new location — the plain sky hides the cut.

**Difficulty:** Medium · **Works on X5:** Yes

## Shoot it
1. Editing-only — works from any clip that has open sky above it at some point (or that you can tilt to find).

## Edit it (phone app)
1. On clip A, keyframe the end so the view tilts up until the frame is entirely sky — rolling the camera 90° first can help fill the frame faster.
2. On clip B, start the same way: all-sky, then keyframe a tilt down 2–3 seconds later onto the new scene.
3. Match the sky type on both sides as closely as you can (both blue sky, or both overcast) — a big mismatch (blue sky cutting to storm clouds) breaks the illusion.
4. Optional: add a short 5-frame cross-fade right at the sky-to-sky join for extra cover.

## Settings
- Any resolution — works best in daylight with a reasonably plain sky (very cloudy or hazy skies transition less cleanly).

## Tips
- This is a good default when the two locations don't share any other visual match point — sky almost always does.
- Pairs well with [Ground Swoop / Portal Transition](ground-swoop-portal-transition.md) as the "opposite" version of the same idea, diving into the ground instead of up to the sky.
