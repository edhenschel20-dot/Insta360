# Pass-By Wipe
A person or object passes very close to the lens and fills the whole frame; the next clip starts the same way and clears to reveal a new location — the pass-by "wipes" the cut.

**Difficulty:** Medium · **Works on X5:** Yes

## Shoot it
1. Clip A: have a person (or hold an object) walk very close past the lens until it fills the frame completely.
2. Clip B: start the same way — frame full of the person/object — then have them move away to reveal the new location.
3. Hands-free version (Best360's "Jump Cut"): mount the camera on a monopod/tripod and walk past it yourself in both locations, then split the clip and reframe afterward.

## Edit it (phone app)
1. Find the frame in clip A where the frame is fully filled by whoever/whatever passed.
2. Find the matching frame in clip B, also fully filled.
3. Cut there. If needed, reframe (grid on) so the pass-by fills the same part of the 360 sphere in both clips.

## Settings
- Any resolution you already shot at — this is a framing and timing trick, not a settings one.

## Tips
- Doesn't need a second camera operator: the hands-free "Jump Cut" version works solo, which fits shooting yourself with the family.
- The original demo of the basic version was filmed in Single-Lens mode — do it in full 360 instead and reframe afterward, so you keep all your 360 options.
