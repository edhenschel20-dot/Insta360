# Hands-Off Triggers
Ways to get everyone — including you — into a group shot, or catch the moment before you pressed record, without ever touching the camera.

**Difficulty:** Easy · **Works on X5:** Yes

## Shoot it
Set these up once in the camera menu (Recording prompts, menu names vary by app version), then use whichever suits the moment:
1. **Gesture:** hand raised = start/stop video.
2. **Peace sign:** holds up a 10-second countdown, then takes a photo — good for a group tiny planet.
3. **Voice:** five set phrases, including "mark" for tagging a moment while you keep rolling.
4. **Twist-to-shoot:** twist the stick twice to start recording — useful with gloves or wet hands.
5. **Pre-recording:** keeps a rolling 30-second buffer before you press the button, so you can catch a moment you reacted to just after it happened.
6. **Timed capture:** starts a Starlapse or timelapse later, up to 10 hours ahead.

## Edit it (phone app)
No edit needed to trigger these — they're shoot-time settings. Once captured, treat photos and clips as normal (see [Tiny Planet Photo Composition](tiny-planet-composition.md) for a peace-sign group photo).

## Settings
- Check Recording prompts in the camera menu before you need any of these — set once, use all trip.

## Tips
- Fits letting it roll: set it up once, then just peace-sign the family photo or say "mark" without stopping to fiddle with the camera.
- Pre-recording is the best fix for "I wish I'd been rolling for that" moments — turn it on by default for anything unpredictable (kids, wildlife).
