# Fake FPV Dive

Reads like an FPV drone diving down a cliff, slope or building face.

**Difficulty:** Medium–Hard · **Works on X5:** Yes

## Shoot it
1. This is a deliberate "hero shot" extra, not something you get from normal rolling footage.
2. Long stick, start high, sweep the camera down and forward along the drop in one smooth motion.

## Edit it (phone app)
1. First keyframe: very wide FOV (ultra-wide reads as FPV).
2. Add further keyframes tracing the "flight path" down.
3. Turn on Motion ND for extra blur, which sells the speed.

## Settings
- 5.7K30 or 8K30. Motion ND on (an in-app motion-blur effect, not a physical filter — menu names vary by app version).

## Tips
- The one-tap version of this idea is [Fly Lapse](fly-lapse.md) — try that first if you want the look without the manual keyframing.
