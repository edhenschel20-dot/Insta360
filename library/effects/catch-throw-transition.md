# Catch / Throw Transition
Throw a ball (or any object) up into the air in one location; cut on the catch and it comes down in a completely different place.

**Difficulty:** Medium · **Works on X5:** Yes

## Shoot it
1. Mouth mount or stick works well — you need both hands free to throw and catch. See [Mouth-Mount / Bite POV](mouth-mount-bite-pov.md).
2. Turn on the reframe grid so you can keep the object centred as it goes up and comes down.
3. Throw the ball (or object) straight up in location A; repeat the same throw height and rhythm in location B.

## Edit it (phone app)
1. Reframe both clips so the object stays roughly centred (grid on helps keep this consistent).
2. Find the exact frame where the object is caught in each clip.
3. Cut precisely on the catch — the throw in A and the catch in B need to line up in height and speed for the illusion to hold.

## Settings
- Higher frame rate (4K60 or similar) makes it easier to find the exact catch frame later.

## Tips
- Practising the throw height once or twice before the take that matters makes the cut much easier to line up — consistent throws are what sells this.
- Works well as a golf-ball variant too — see [Golf Swing + Fake Ball Flight](golf-swing-fake-ball-flight.md) for a related idea with a longer flight path.
