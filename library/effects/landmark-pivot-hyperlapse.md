# Landmark Pivot Hyperlapse
Walk a long, smooth loop around a landmark while it stays pinned in the same spot in frame — sped up, the world spins around it while the landmark itself barely moves.

**Difficulty:** Medium · **Works on X5:** Yes

## Shoot it
1. Stick held above head height.
2. Walk a smooth path around the landmark — following an existing kerb, path or track edge makes it much easier to keep the pace and radius consistent than trying to freehand a circle.

## Edit it (phone app)
1. Keyframe every so often (every few seconds, or wherever the path curves), keeping the same reference point on the landmark lined up on the same grid line each time.
2. Set clip speed to 32×.
3. Test the result both with and without Motion ND — Ben Claremont notes it can go either way depending on the footage, so try both rather than assuming.

## Settings
- 5.7K30 or higher — a hyperlapse this long benefits from extra detail to reframe from.

## Tips
- This is a longer, more deliberate version of a normal hyperlapse (see [Hyperlapse / TimeShift](hyperlapse-and-timeshift.md)) — it needs several minutes of walking to pay off, so it's a "when you have the time" shot, not a quick one.
- A genuinely circular path (a roundabout, plaza, or monument with a walkway round it) makes this much easier than an open field.
