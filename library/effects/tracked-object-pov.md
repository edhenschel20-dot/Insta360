# Tracked-Object POV

A ball, tool, cup or hand-held object stays dead centre in frame while the world moves around it.

**Difficulty:** Medium · **Works on X5:** Yes

## Shoot it
1. Mount the X5 on a mouth mount or chest mount, then hold, throw or pass the object as normal.

## Edit it (phone app)
Use [Deep Track](../editing/deep-track.md) with the "Universal Tracker" set on the object — helmets, cups and phones are supported object classes. Or hand-keyframe the object to stay centred if Deep Track loses it.

## Settings
- 5.7K30 or higher fps if the object moves fast.

## Tips
- Deep Track can't be combined with keyframes or Movement templates on the same clip — pick one approach and stick with it for that clip.
