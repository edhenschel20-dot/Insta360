# Boat / Jet-Ski Rear-Deck Drone & Side-Out Stick
A mounted version of the [Boat Selfie / Off-the-Stern Shot](boat-selfie-off-the-stern.md) — clamped to the boat or jet-ski itself instead of held, so it can run the whole ride hands-free.

**Difficulty:** Medium  ·  **Works on X5:** Yes

## Shoot it
1. **Rear-deck drone follow:** extended stick clamped to the rear deck or rail, pointing back and up, to mimic a drone tailing the boat.
2. **Side-out:** stick clamped out to the side at wave height, for a "riding alongside" look.
3. Start recording with the GPS remote and let it run the whole ride rather than reaching for the camera.
4. **Kayak/paddleboard:** a monopod clamped to the deck works the same way; keep the stitch line pointing away from the paddler so the paddling motion doesn't cross it.

## Edit it (phone app)
1. Reframe to the angle you actually want from the mounted position — front, side, or rear.

## Settings
- 5.7K30, Motion ND on for extra blur at speed. Full reference: [Fast motion & driving settings](../settings/fast-motion-and-driving.md).
