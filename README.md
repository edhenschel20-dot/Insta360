# Insta360 X5 Guide

A personal guide to shooting and editing with the Insta360 X5: settings,
shot recipes, creative effects, and step-by-step edits in the Insta360 app.
It's built with help from Claude Code agents (see `CLAUDE.md`).

- `docs/` holds research reports and decisions (start with `docs/VERDICT.md`).
- `library/` holds the searchable effects & techniques library (coming soon).
