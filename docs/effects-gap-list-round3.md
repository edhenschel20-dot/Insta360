# Effects gap list, round 3 — the hard-to-find events, the island trip, everyday family life, and AI effects

Researched 2026-09-26 for the Insta360 X5 + phone app. Round 1 is `effects-gap-list.md`, round 2 is `effects-gap-list-round2.md` (129 effects now exist; see `library/effects/index.md`). This round targets four things: **(1) the events earlier rounds could not source** (luau/fire dancers, parades, glow sticks, surfing/bodyboarding, golf swing analysis), **(2) tropical-island trip shots** (whales, waterfalls, summit sunrise, dark-sand beaches, rainbows, tide pools, silhouettes, resort pools, doors-on helicopter), **(3) Everyday & walking**, which has only 17 effects (dog walks, backyard, birthdays, Christmas morning, sports practice, playgrounds, road-trip stops), and **(4) the app's AI Effects scene list**.

Every YouTube ID below was verified live with the oEmbed endpoint (HTTP 200) on 2026-09-26 (87 IDs checked; two candidates that returned 401 were dropped). Start times (`@seconds`) come from the video's own chapter markers (yt-dlp), or from the auto-transcript where a chapter had none (marked *≈*). Upload dates are from yt-dlp metadata.

**How to read the tables.** Columns follow the spec front matter: *Category* is the `category:` slug, *Good for* the `good_for:` slugs (1–4). *X5?* = works on the X5 (yes / likely / unknown). **[general advice]** marks a page that has no 360-specific tutorial behind it; the *Sources* cell says what it is based on (non-360 action-cam technique that transfers, plus sound general photography practice). Where the example was shot on a GoPro, a GO 3S or an older X-series camera, the *How* cell says how Ed adapts it (let it roll, always full 360, he's in shot).

**Search caveat.** This round searched harder than round 2 and got further, but written sources are still thin: (a) **YouTube via yt-dlp** worked well (about 120 search queries, ~55 transcripts read, chapter markers used for start times); (b) **old.reddit.com JSON** answered one request then returned a "Welcome to Reddit" login wall / HTTP 302 for everything after, so the r/Insta360 "Ghost rider" thread (2026-01-14) is still unread; (c) **forums.insta360.com** is a JavaScript app whose backend (`service-g.insta360.com/forum-service`) rejects unauthenticated queries with HTTP 400; (d) **insta360.com/blog** loads (the 2025-12-30 holiday AI-effects post was read) but has no post listing the AI Effects scenes; (e) **Bing** returned only generic Insta360 pages; (f) the **App Store / Play Store** listings name Shot Lab templates but not AI Effects scenes; (g) YouTube's caption endpoint rate-limited (HTTP 429) six videos, listed at the end as "needs a watch". Items that could not be sourced at all are in "Not found" at the end.

**Two things to check before building pages.** (1) Several items below are **[general advice]** by design, because no 360 tutorial exists for them; they are written from transferable action-cam technique and general practice, and should keep the tag on the page so Ed knows they are not tested recipes. (2) Some items fit better as **shot plans** (a one-event step-by-step like `library/shots/lighted-parade.md`) than as effect pages; the shot-plan section at the end says which.
